# Overview

This is a reusable template to scaffold a .net 10 minimal API. 

## Pre requisite

- Cookiecutter: Install cookie cutter following instructions [here](https://cookiecutter.readthedocs.io/en/stable/installation.html)

## Usage

Generate your project from the project template using command:

```
cd <root-of-this-repo>/apps
cookiecutter ../templates/minimal-api/
```
